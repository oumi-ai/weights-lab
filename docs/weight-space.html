Data, provenance & limits

This visualization combines an offline checkpoint audit with a saved NVIDIA H200 reference run. Oumi Weights Lab replayed the released edit by Takehi, Teoh, Zhang, and Khattab. The replay and the benchmark are separate checks.

  • The checkpoint audit compared raw-byte SHA256 hashes for all 488 stored tensors at pinned model revisions. Only the two matrices shown above differed; 130,188 entries changed. Replay used zero forward passes and restored the original weights exactly on undo.
  • The saved benchmark has 500 problems and four generated samples per problem, per arm. Thinking enabled; temperature 0.6, top-p 0.95, top-k 20, presence penalty 1.5, seed 0. The token cap is 32,768 generated tokens; a capped sample finished with finish_reason == length.
  • The visualization recounts saved sample records. Answers were not regraded and inference was not rerun for this audit. There was no benchmark of the fully undone model. The upstream dataset revision was unpinned; the local run records its exact revision.
